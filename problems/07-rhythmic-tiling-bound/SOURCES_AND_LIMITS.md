# Sources, reuse, and novelty limits

The paper gives the full reference list and search limitations. The extremal queens problem already appears as [OEIS A352241](https://oeis.org/A352241); perfect rhythmic triplet tilings are catalogued as [OEIS A261516](https://oeis.org/A261516). The targeted prior-art search did not establish priority, and did not obtain all potentially relevant full texts. The linked packing literature does not make this package an eventual-existence proof.
